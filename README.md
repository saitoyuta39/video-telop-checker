# 動画内テロップ誤字脱字チェッカー (Video Subtitle Checker)

Gemini 1.5 のロングコンテキスト機能を活用し、動画内のテロップと発話内容を照合して誤字脱字や不一致を自動検出するツールです。

## 主な機能

1.  **マルチモーダル解析**: 映像（OCR）と音声（Speech-to-Text）を同時に解析し、テロップの誤りと発話内容との齟齬をチェックします。
2.  **AI 校正ロジック**: 
    *   **初級チェック**: タイポ、変換ミス、送り仮名。
    *   **文脈チェック**: 不自然な日本語。
    *   **YouTube 最適化**: 意図的なスラングや絵文字は無視。
3.  **モデル選択**: 最新の Gemini 3 シリーズ（`3.1 Pro`, `3 Flash`, `3.1 Flash-Lite`）を切り替え可能。
4.  **カスタムガイドライン**: 現場固有の「NGワードリスト」や「表記ガイドライン」をプロンプトに動的に注入。
5.  **タイムコード付きレポート**: エラー箇所を正確な時間とともにリスト化し、修正案を提示。

## セットアップ

### 1. API キーの取得
[Google AI Studio](https://aistudio.google.com/) から API キーを取得してください。

### 2. 環境変数の設定
`.env.local` ファイルを作成し、取得した API キーを設定します。

```env
GEMINI_API_KEY=your_api_key_here
```

### 3. ローカルでの実行
```bash
npm install
npm run dev
```

### 4. Vercel へのデプロイ
1.  リポジトリを GitHub にプッシュします。
2.  Vercel でプロジェクトを作成し、環境変数 `GEMINI_API_KEY` を設定します。
3.  デプロイを実行します。

## 注意事項
*   Vercel の無料プラン（Hobby）では、サーバーレス関数のタイムアウト制限やリクエストボディのサイズ制限（4.5MB程度）があるため、長尺動画を処理する場合は有料プランの検討、または動画をクラウドストレージ（S3など）に事前にアップロードする構成への変更が推奨されます。
*   Gemini 1.5 Flash は、1分あたり数円程度の非常に低いコストで動作します。
